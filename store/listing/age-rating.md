# Age rating questionnaire (IARC) answers

Partner Center > the submission > Age ratings. Start the questionnaire.

- Contact email for the IARC certificate: your Partner Center email.
- Category: **All other app types** (it is a utility: not a game, not a social, browser or dating app).

Answer every content question **No**:

| Question (short form) | Answer |
|---|---|
| Violence, blood, gore, or depictions of it | No |
| Fear, horror, frightening content | No |
| Sexual content or nudity | No |
| Crude humour, language, profanity | No |
| Drugs, alcohol, tobacco (use or references) | No |
| Gambling, simulated gambling, loot boxes | No |
| Discrimination or hate | No |
| Does the app let users interact or exchange content with each other (chat, posting, sharing)? | No |
| Does the app share the user's physical location with other users? | No |
| Does the app allow purchases of digital goods? | No |
| Does the app provide unrestricted internet access (for example a web browser or search engine)? | No |
| Is the app primarily a web browser or search engine? | No |
| Does the app collect or share personal information with third parties? | No |

Expected result: the lowest rating in every region (for example IARC 3+, ESRB Everyone, PEGI 3, USK 0).

Why every answer is No: Screentime only shows the user's own app usage on their own PC. It has no user-generated content, no communication between users, no purchases and no network access.
